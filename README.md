# PowerBI_Analise_de_Produtos
📦 Relatório de Análise de Produtos

Este projeto apresenta um painel interativo desenvolvido no Power BI com o objetivo de analisar o desempenho de vendas de um produto específico (neste caso, Celular Modelo 3). O relatório oferece uma visão clara sobre receita, metas, desempenho por vendedor e sazonalidade de vendas por cliente ao longo do ano.
Segue link para acesso ao relatorio: https://app.powerbi.com/view?r=eyJrIjoiYjdlNzI1NDYtNzNhZi00YjViLTg3MWMtYTA2YTVkMjI0MzhhIiwidCI6Ijg1ZGU1OTA5LTZlOGItNGEwYy1iYTIzLWYwMzYyYzcyZDc3NiJ9

Obs: Consta um segundo modelo para versão de celular, basta escanear o QRCODE pelo celular ou clicar no icone para ver a versão mobile.

📊 Funcionalidades

    Seleção dinâmica do produto analisado

    Receita total gerada no período

    Total de pedidos e itens vendidos

    Comparativo de desempenho em relação à meta estipulada

    Análise de vendas por vendedor

    Mapa de calor mostrando os meses com maior volume de vendas por cliente

📌 Insights Possíveis

    Identificação dos principais vendedores em termos de receita

    Clientes com maior volume de compra em determinados períodos do ano

    Acompanhamento da performance de vendas comparada à meta

    Tomada de decisões para ações comerciais, como promoções e campanhas sazonais

🛠️ Tecnologias Utilizadas

    Power BI

    Microsoft Excel (arquivo: Base de Dados.xlsx) para armazenamento e manipulação de dados
